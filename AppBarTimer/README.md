## 1. .exe ファイルに出力（ビルド）する方法

開発用のデータを省き、本番用の最速・最軽量状態（Releaseモード）で出力する手順です。

1. **モードの切り替え**
   - Visual Studio上部の「▶ 開始」ボタンの左側にあるドロップダウンを `Debug` から **`Release`** に変更します。
2. **ビルドの実行**
   - 上部メニューから **「ビルド」 ＞ 「ソリューションのビルド」** をクリックします。
   - ※画面下に「ビルド: 1 正常終了」と表示されれば成功です。
3. **完成したファイルを取り出す**
   - 右側の「ソリューションエクスプローラー」で、プロジェクト名（`AppBarTimer`）を右クリックします。
   - **「エクスプローラーでフォルダーを開く」** をクリックします。
   - 開いたフォルダから **`bin` ＞ `Release` ＞ `net8.0-windows`** の順に開きます。
   - その中にある **`AppBarTimer.exe`** が完成した実行ファイルです。

## 2. アプリを常駐させる方法（スタートアップ登録）

Windows起動時に自動でアプリを立ち上げる、最も安全で管理が簡単な手順です。

1. **ショートカットの作成**
   - 出力した **`AppBarTimer.exe`** を右クリックし、**「ショートカットの作成」** をクリックします。
2. **スタートアップフォルダを開く**
   - キーボードの **`Win` キー ＋ `R` キー** を同時に押します。
   - 「ファイル名を指定して実行」のウィンドウが開いたら、名前の欄に **`shell:startup`** と入力して「OK」を押します。
3. **ショートカットの配置**
   - 開いたスタートアップフォルダの中に、手順1で作成したショートカットファイルを移動（またはコピー）させます。
   - ※不要になった場合は、このフォルダからショートカットを削除するだけで常駐を解除できます。
